# Übungstimer

Ein einfacher, für iPhone-Browser optimierter Timer für physiotherapeutische Übungen. Stelle Wiederholungszahl, Übungsdauer und Pause ein. **Start/Pause** beginnt oder unterbricht den Timer; **Stopp** setzt ihn zurück.

## Auf dem iPhone verwenden

1. Die Dateien auf einen Webserver mit HTTPS laden. Service Worker – und damit Offline-Nutzung – funktionieren aus Sicherheitsgründen nur über HTTPS (oder lokal auf `localhost`).
2. Die Seite einmal in Safari öffnen und warten, bis „Offline bereit“ angezeigt wird.
3. Optional in Safari **Teilen → Zum Home-Bildschirm** wählen. Danach lässt sich die App wie eine eigenständige App starten.
4. Nach dem ersten erfolgreichen Laden funktioniert der Timer auch ohne Internetverbindung.

Es werden keine externen Bibliotheken oder Netzwerkdienste benötigt. Bei einer Aktualisierung der App muss sie einmal online neu geladen werden.
